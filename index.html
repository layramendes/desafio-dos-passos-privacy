Política de Privacidade

Aplicativo: Desafio dos Passos
Pacote: com.protecon.desafiodospassos
Última atualização: 27 de abril de 2026

Esta Política de Privacidade descreve como o aplicativo Desafio dos Passos, desenvolvido pela Protecon, coleta, usa e protege as informações dos usuários.

1. Informações que coletamos

  • Dados de atividade física: O app utiliza o sensor de movimento do dispositivo para contar os passos diários do usuário.
  • Dados de conta: Nome, endereço de e-mail e foto de perfil fornecidos durante o cadastro.
  • Fotos: Imagens selecionadas pelo usuário da galeria ou capturadas pela câmera para uso como foto de perfil.
  • Dados de uso: Histórico de passos, metas, conquistas e participação em desafios.

2. Como usamos as informações

  • Exibir o progresso diário e histórico de passos do usuário.
  • Permitir a participação em desafios e rankings entre usuários.
  • Personalizar a experiência com metas e conquistas (badges).
  • Autenticar o usuário de forma segura.
  • Enviar notificações relacionadas ao app (metas, desafios, conquistas).

3. Armazenamento e segurança

Os dados são armazenados de forma segura utilizando o serviço Supabase, com criptografia em trânsito (HTTPS/TLS). Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais.

4. Permissões utilizadas

  • Reconhecimento de atividade (ACTIVITY_RECOGNITION): Para contar os passos diários usando o sensor de movimento do dispositivo.
  • Câmera: Para capturar uma foto de perfil, somente quando solicitado pelo usuário.
  • Galeria de fotos: Para selecionar uma imagem existente como foto de perfil.

5. Dados de menores

O aplicativo não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados desse público. Caso tomemos conhecimento de coleta inadvertida, os dados serão removidos imediatamente.

6. Retenção e exclusão de dados

O usuário pode solicitar a exclusão completa de sua conta e todos os dados associados diretamente nas configurações do aplicativo, na seção "Conta" → "Excluir conta".

7. Alterações nesta política

Podemos atualizar esta política periodicamente. Notificaremos os usuários sobre mudanças significativas por meio do próprio aplicativo. O uso contínuo do app após as alterações implica aceitação da nova política.
